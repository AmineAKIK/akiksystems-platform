# AkikSystems Platform

AkikSystems is a public bilingual platform for Systems, Writings, Learning,
Profile and collaboration surfaces.

The repository intentionally has **no back-office**. Editorial and structural
changes are made through code, reviewed in Git, qualified by CI, and deployed
through the normal application pipeline.

## Architecture

This pnpm monorepo contains:

- `apps/web` — React Router Framework Mode application served by Express.
- `apps/worker` — Graphile Worker runtime for asynchronous application jobs.
- `packages/core` — shared domain contracts.
- `packages/db` — Kysely/PostgreSQL persistence and public read-model logic.
- `packages/ui` — shared presentation primitives.
- `packages/config` — runtime configuration and observability contracts.

Runtime infrastructure remains deliberately separate from editorial tooling:

- PostgreSQL stores public-domain state, relations, publication snapshots,
  inquiries and job state.
- Object storage serves contextual public assets through guarded application
  routes.
- Graphile Worker delivers asynchronous Work with us notifications.
- Railway owns the web, worker and PostgreSQL deployment topology.

There is no administrator login, private dashboard, CMS editor, authenticated
preview surface or in-application publication control plane.

## Content workflow

Content changes are code changes.

A normal update follows this path:

1. create a branch;
2. change the relevant domain/bootstrap/content code;
3. add or update migrations when persistent state must change;
4. run the qualification suite;
5. open and review a pull request;
6. merge to `main`;
7. Railway runs `pnpm deploy:migrate` before the new web deployment.

Existing publication snapshots remain a runtime isolation boundary for public
reads. They are mutated only through reviewed code paths and explicit
provisioning/migration logic, never through a browser administration surface.

Code-backed provisioning commands include:

```sh
pnpm content:bootstrap-l4-reference-systems
pnpm content:bootstrap-dwwm
pnpm content:bootstrap-sentinel-dossier
pnpm content:bootstrap-rendre-attention-essay
```

These commands are explicit operations for development, recovery or reviewed
content changes. Schema migrations do not silently recreate portfolio evidence.

## Public application

The web application exposes localized EN/FR routes for:

- Home
- Profile
- Systems and System details
- Writings, Categories and Tags
- Learning, Trainings, Credentials and Learning Artifacts
- Work with us
- Privacy, legal notice and cookies

The root route redirects to `/en`.

## Work with us runtime

The contact flow is application infrastructure, not a back-office:

```text
public form
  -> PostgreSQL inquiry
  -> Graphile Worker job
  -> configured email transport
```

Submission tokens provide idempotency and the database enforces a bounded
per-email rate limit. Notification delivery state is retained for reliable
asynchronous processing.

## Assets

Contextual media is stored in S3-compatible object storage. Public asset routes
serve only assets referenced by the corresponding public snapshot. Responsive
image variants are generated by the web runtime with libvips.

Required storage configuration:

```text
BUCKET
REGION
ENDPOINT
ACCESS_KEY_ID
SECRET_ACCESS_KEY
```

## Runtime configuration

Core web variables:

```text
NODE_ENV
PORT
DATABASE_URL
```

Optional worker email transport:

```text
WORK_WITH_US_EMAIL_PROVIDER=resend
RESEND_API_KEY=...
WORK_WITH_US_EMAIL_FROM=...
```

No authentication or administrator credentials are required by the platform.

## Commands

Install and validate:

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Database:

```sh
pnpm db:migrate
pnpm db:check
pnpm deploy:migrate
```

Local runtimes:

```sh
pnpm dev:web
pnpm dev:worker
```

Primary smoke checks:

```sh
pnpm smoke:web
pnpm smoke:observability
pnpm smoke:worker
```

The CI workflow additionally verifies the public Profile, System technology
evidence, publication snapshots, Work with us persistence/notification state,
and responsive Home behavior in Chromium.

## Deployment

Railway production and staging each retain:

- one web service;
- one worker service;
- PostgreSQL;
- object storage configuration;
- environment-specific secrets.

The web healthcheck is `GET /health`, which verifies PostgreSQL connectivity.
Content URLs are not infrastructure healthchecks because unpublished resources
may legitimately return 404.

Normal web pre-deploy command:

```sh
pnpm deploy:migrate
```

## Design principle

AkikSystems is a platform with a public application runtime, not a CMS.

If a public surface needs to change, the change belongs in code and goes through
the same branch, review, qualification and deployment discipline as the rest of
the product.
